# Apps Script 初期設定

Googleフォームの回答スプレッドシートで使うスクリプトです。

## 利用者が行うこと

1. 回答スプレッドシートを開く。
2. **拡張機能 → Apps Script** を開く。
3. `Code.gs` の内容をすべて貼り付けて保存する。
4. 関数一覧から `setupPradioZ` を選び、**実行**を1回押す。
5. Googleの権限確認を許可する。

これだけで、以後のフォーム回答を自動処理します。

## 自動で行うこと

- `FV_IMAGES_JSON` 列を作る。
- フォーム送信トリガーを作る。
- JPEG / PNG / WebPだけを画像として扱う。
- 画像を **「リンクを知っている全員・閲覧者」** に変更する。
- サムネイルと拡大表示用URLを `FV_IMAGES_JSON` に保存する。

既存回答も処理したい場合は、スプレッドシートを再読み込みした後、上部の **P_RADIO_Z → すべての回答を再処理** を使えます。

> 注意: この簡易版では、画像URLを知っている人は画像を閲覧できます。機密画像には使わないでください。
